Explorer la sécurité des paiements par un projet concret

Un projet personnel qui relie analyse technique, sécurité et exigences de conformité.

Scanner de détection Magecart (PCI DSS 4.0), en cours

Le Magecart, ou web-skimming, vole les données de carte directement dans le navigateur du client, par l’intermédiaire d’un script tiers compromis sur la page de paiement. Les contrôles côté serveur ne voient pas ce qui s’exécute dans le navigateur. Depuis le 31 mars 2025, PCI DSS 4.0 demande donc d’inventorier et de vérifier l’intégrité des scripts de la page de paiement (exigence 6.4.3) et de détecter toute modification de cette page (exigence 11.6.1).

Mon projet est un scanner en Python et Playwright, dont la première version (v0.1) est publiée en open source sur GitHub. Il est pensé pour devenir un plugin WooCommerce utilisable par une PME sans équipe sécurité. À terme, il devra inventorier les scripts d’une page de paiement avec une empreinte SHA-256, comparer deux scans pour repérer un script modifié ou ajouté, appliquer des règles anti-skimming (domaines inconnus, code obfusqué, requêtes sortantes suspectes) et produire un rapport de conformité horodaté et exportable. Ce rapport aide à préparer un audit, il ne remplace pas l’évaluation d’un auditeur (QSA).

  • Déjà réalisé : étude des exigences PCI DSS 4.0 et du cycle d’attaque Magecart, architecture et définition du MVP, puis un premier prototype v0.1 : inventaire des scripts d’une page avec empreinte SHA-256, comparaison entre deux scans, liste blanche de domaines, et banc d’essai local avec un faux script tiers inoffensif.
  • À venir : détection des requêtes sortantes suspectes, alertes par email ou webhook, rapport de conformité exportable, puis interface du plugin WooCommerce.
